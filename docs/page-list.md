# Page List and Use

## Root
- `index.html` - Public landing page.
- `login.html` - Common login for Admin, Staff, and optional Customer.

## Admin Pages
- `admin-dashboard.html` - Admin summary dashboard.
- `manage-users.html` - View users.
- `add-user.html` - Add staff/admin account.
- `edit-user.html` - Edit user account.
- `manage-customers.html` - View/search customers.
- `manage-vehicles.html` - View/search vehicles.
- `manage-packages.html` - View wash packages.
- `add-package.html` - Add package.
- `edit-package.html` - Edit package.
- `manage-bookings.html` - View bookings.
- `booking-details.html` - View one booking.
- `manage-payments.html` - View payments.
- `daily-report.html` - Daily report.
- `weekly-report.html` - Weekly report.
- `ai-insights.html` - AI insights and busy day note.
- `system-settings.html` - System settings.
- `admin-profile.html` - Admin profile.

## Staff Pages
- `staff-dashboard.html` - Staff dashboard.
- `add-customer.html` - Add customer.
- `customer-list.html` - View customers.
- `customer-details.html` - Customer details.
- `add-vehicle.html` - Add vehicle.
- `vehicle-list.html` - View vehicles.
- `create-booking.html` - Create booking.
- `booking-list.html` - View bookings.
- `update-booking.html` - Update booking.
- `cancel-booking.html` - Cancel booking.
- `record-payment.html` - Record payment.
- `payment-list.html` - View payments.
- `receipt.html` - Printable receipt.
- `ai-package-recommendation.html` - Rule-based AI package recommendation.
- `staff-profile.html` - Staff profile.

## Customer Pages Optional
- `customer-dashboard.html` - Optional customer dashboard.
- `view-packages.html` - View packages.
- `request-booking.html` - Request booking.
- `my-bookings.html` - Customer booking list.
- `booking-status.html` - Booking status.
- `customer-profile.html` - Customer profile.
